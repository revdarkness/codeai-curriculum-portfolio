# David Berry — CS & AI Curriculum Portfolio

A focused portfolio for CodeAI's Manager, CS & AI Curriculum role. The site connects David Berry's K–12 curriculum leadership, engineering design practice, robotics programs, applied AI work, and technical writing.

## Deploy to Vercel

1. Import this repository in Vercel.
2. Keep the framework preset as **Other**.
3. Deploy. The included `vercel.json` serves the `dist` directory with no build step.

## Local preview

Open `dist/index.html` in a browser, or serve the repository with any static file server.

## Structure

- `dist/index.html` — page content and metadata
- `dist/styles.css` — responsive presentation and print styles
- `dist/site.js` — progressive navigation and reveal enhancements

All content is static HTML, CSS, and JavaScript with no external runtime dependencies.
